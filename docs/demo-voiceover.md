# Family Loop — 5-minute voiceover

No timestamps. Speak at a calm demo pace. Pause where a screen needs to catch up.

Use: Meera door (blue) · Aarav door (dark green) · LM Studio selected · Fast-forward family.

---

Phones already enforce. The problem is not the lock. The problem is the parent living inside Screen Time.

This is Family Loop. An Everyday Agent for one family in Bengaluru. Meera is the parent. Aarav is thirteen. His phone already has Digital Wellbeing. She should not have to live in it too.

Family Loop is not MDM. It does not lock the device. It does not scrape chats. It is an inbox around the operating system. Agents remind, compare, and ask. Meera only shows up for a real yes or no.

Two doors. Blue is Meera. Dark green is Aarav. The child cannot change the rules, and he cannot approve himself.

In the header: Bedrock, or LM Studio. We are on LM Studio, a local model, so the desk can reason without waiting on cloud credits. Deterministic Python still owns policy. The model may explain. It cannot bypass a must-ask rule.

Six specialists sit under one orchestrator we call the Family Desk. Setup coach writes the policy. Request triage files an ask. Check-in runner stores a Screen Time paste. Digest writer builds Sunday. Override clerk logs Meera’s decision. When an agent actually runs, its pet pops on the top right, in its colour, with its name — then it leaves. You are not watching a chatbot. You are watching work.

Open Meera.

This is Home. Not another dashboard of every ping. Family Loop is about attention. How many things are urgent. How many need a decision. How many are only informational. The thesis is simple: reduce family noise to decisions that matter.

Needs you is the inbox. Today is the calendar. This week is adherence and check-ins. What changed is the week in one paragraph. Family Desk shows tool-level traces — policy loaded, snapshot compared — not the model talking to itself.

Rules is setup, not a second home. Age, school hours, ask-first, hard no. Social is red. Education is green. Games are orange. Money is purple. Meera writes house rules in plain language. The agent writes the Family Policy JSON. She ticks the locks the phone already has. Unchecked locks mean Sunday goes red, because detection is weak. We never claim we flipped the OS.

Leave. Open Aarav.

He can ask: visit a site, install an app, extra time, a new in-app friend. He can paste a Screen Time list, or upload a photo and we read it to text. He cannot see Meera’s queue. He cannot change policy.

He asks for Reddit. Watch the top right. Desk routes. Triage reads policy, request history, and the calendar. Reddit is social. Social is never a silent yes. The ask stays pending.

Back to Meera. Fast-forward family.

The clock does not wait for a real Saturday. Check-in is requested. A snapshot arrives. Discord is on the list. Discord was never approved. Family state updates. Then Sunday.

This is the wow. Family Desk hands the week to Digest writer. Policy loaded. Seven-day history loaded. Snapshot compared. Missed pings checked. Pending decisions checked. Exceptions classified. Digest filed. A simulated WhatsApp is sitting in the outbox, labelled simulated.

Sunday envelope. Three buckets only.

Red: Discord detected — a new app with no approval. Reddit ignored — Meera did not show up for the yes or no.

Needs you: Reddit. Still waiting.

Green: the Saturday file was in. Time under cap, if the paste says so.

Open Decisions.

Discord is an exception from a snapshot, not a chat. Allow adds it to the approved list. Deny records the no. Aarav cannot press this. Reddit is still must-ask, even if he has asked three times. History changes the explanation. It does not change the rule.

If she allows Reddit once, Override clerk logs it. That is memory, not a vibe.

Family state is why the name is Loop. Policy. People. Approvals. Routines. Patterns. Unresolved decisions. Observe, remember, reason, ask, decide, observe again.

Timeline is the same week as a story, not a log dump.

Calendar is live. Saturday is submission. Sunday is evaluation. Passed days are crossed. Parent and child can add real events. The OS still does not get remote-controlled from here.

That is the architecture. An event hits family state. The Family Desk routes. Specialists read policy, history, and calendar. Deterministic tools write the store. The parent decides. The loop continues.

We did not add ten more agents. We did not add a parenting chatbot. We did not lock the phone. We did not predict addiction. The strength is the boundary.

The operating system still enforces. The agents coordinate. The parent decides.

Family Loop.
