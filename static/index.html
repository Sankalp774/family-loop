How the desk works

Six specialists. One knock.

They run in the background. You only see a card when a human has to say yes or no.

  1. Family desk — orchestrator. Routes “new ask”, “ping due”, and “it’s Sunday” to the right specialist.
  2. Setup coach — turns Meera’s answers into a Family Policy. Does not only chat.
  3. Request triage — allow, deny, or ask parent. No silent yes on social, money, or new contacts.
  4. Check-in runner — Saturday file + random Screen Time pings. Stores the paste the human made.
  5. Digest writer — Sunday Red / Needs you / Green, then a WhatsApp-shaped letter.
  6. Override clerk — logs Meera’s yes/no and one-off exceptions. Aarav cannot approve himself.
